# Student Feedback & Performance Analytics Dashboard 📊

## 📌 Project Overview
This project was developed as part of a **Summer Internship**. The goal was to analyze student survey data from **Western Maharashtra** to understand academic performance, teaching satisfaction, and course effectiveness.

## 🛠️ Tech Stack
- **Power BI Desktop**: Data Visualization & Dashboarding
- **DAX (Data Analysis Expressions)**: Custom measures for Satisfaction Rates %
- **Power Query**: Data Cleaning and Transformation
- **Excel/CSV**: Source Data

## 📋 Key Features & Insights
- **Course Impact**: Identified the most effective courses (Python, SQL, Power BI).
- **Academic Trends**: Visualized performance distribution from <40% to >80%.
- **Teacher Feedback**: Analyzed satisfaction levels and faculty availability.
- **Geographic Insights**: District-wise student distribution across Sangli, Kolhapur, and Satara.

## 📊 Dashboard Visuals
1. **Experience vs Performance**: A Line chart showing how academic experience impacts results.
2. **Course Success Rate**: A Pie chart breaking down the effectiveness of different subjects.
3. **Satisfaction Flow**: A Waterfall chart showing the breakdown of student satisfaction.
4. **Student Distribution**: A Bar chart for geographic analysis.

## 📂 Project Structure
- `Student_Analytics_Dashboard.pbix`: The main Power BI project file.
- `student_responses_cleaned.csv`: The cleaned dataset used for analysis.
- `Screenshots/`: Folder containing dashboard images.

## 🚀 How to Use
1. Clone this repository.
2. Open `Student_Analytics_Dashboard.pbix` in **Power BI Desktop**.
3. If data doesn't load, update the data source path to point to the `student_responses_cleaned.csv` file.
